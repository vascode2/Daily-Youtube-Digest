**핵심 요약**
Osmantic 창업자 Ahmad Osman이 CODE Summit 2026에서, 쓸 만한 로컬 모델을 확보한 뒤에도 실제 워크로드에 맞는 스택을 어떻게 고를지 단계별로 설명한다. 양자화와 메모리 대역폭, 배치 처리 같은 하드웨어·엔진 문제에서 출발해 에이전트 하네스와 특화 모델 선택, GPU 보유 경제성으로 논의를 넓힌다. 마지막에는 직접 통제하는 장비에서의 지속 학습 필요성을 주장한다.

1. **하드웨어와 추론 엔진 선택**
   - 양자화가 모델 품질에 미치는 영향과, 프리필(prefill)과 디코드(decode) 단계의 병목 차이를 구분해 하드웨어를 고르는 기준을 다룬다.
   - 배치 처리와 칩별로 적합한 추론 엔진이 다르며, 추측 디코딩(speculative decoding) 등 파이프라인 최적화로 성능을 더 끌어올릴 수 있다고 설명한다.

2. **에이전트 워크로드와 하네스**
   - 벤치마크만으로는 에이전트 워크로드를 판단하기 어렵다고 보고, 에이전트가 만든 트레일러 사례와 Portal 하네스를 보여준다.
   - 로컬 에이전트가 제대로 동작하려면 모델뿐 아니라 검색 기능을 포함한 완전한 하네스가 필요하다고 강조한다.

3. **실제 작업 트레이스 기반의 특화 모델 선택**
   - 범용 벤치마크 대신 실제 작업 트레이스(evaluation traces)를 근거로 용도에 맞는 특화 모델을 고르라고 제안한다.

4. **GPU 보유·임대의 경제성**
   - GPU를 빌리는 경우와 직접 소유하는 경우의 비용과 운영상 트레이드오프를 비교한다.
   - 이미 가진 하드웨어에서 앞으로 나올 더 강력한 모델을 돌릴 수 있도록 미리 계획하라고 조언한다.

5. **로컬 AI와 지속 학습**
   - 지속 학습(continual learning)은 직접 통제하는 로컬 환경에서 가능하다고 주장한다.
   - 엔그램(engram), 의사결정 모델, 가중치 편집(weight edits) 같은 방향을 후반부에 소개한다.

   - Anthropic 연구원 Levent Alpöge는 자신과 Claude가 수학의 "성배"로 불리는 167년 된 리만 가설의 증명을 발견했다고 주장했습니다.
