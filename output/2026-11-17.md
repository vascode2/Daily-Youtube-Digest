## [2026 in LLMs — Simon Willison](https://www.youtube.com/watch?v=9RKrSF9d2SE)

**한 줄 인사이트**
💡 코딩 에이전트가 신뢰할 만한 수준에 도달한 것이 2026년 LLM의 가장 큰 변곡점이며, 그럼에도 소프트웨어 엔지니어링은 오히려 더 어려워졌다고 느껴진다는 것이 핵심 문제의식이다.

**핵심 요약**
Datasette 창시자 Simon Willison이 CODE Summit 2026에서 LLM의 세 가지 변곡점인 신뢰할 수 있는 코딩 에이전트, 끈질긴 문제 해결, 바이브 코딩 게임 개발을 짚습니다. 40개 상자 속에 숨은 삐 소리 감지기를 찾은 사례 같은 실제 경험과 펠리컨 벤치마크, 프롬프트 인젝션, 폭주 에이전트 문제를 오가며 논지를 쌓습니다. 마지막에는 생산성이 높아졌는데도 왜 개발이 더 힘들게 느껴지는지 묻습니다.

1. **코딩 에이전트의 변곡점과 2026년 전망**
   - 코딩 에이전트가 안정적으로 동작하기 시작한 시점을 LLM 발전의 전환점으로 제시합니다.
   - 이로 인해 개발자들이 더 야심 찬 프로젝트에 도전하게 되었고, 2026년에 대한 예측도 함께 다룹니다.

2. **모델 벤치마크와 보안 이슈**
   - 펠리컨과 앵무새 같은 이미지 생성 벤치마크로 모델 성능을 가늠하는 방식을 소개합니다.
   - 프런티어 모델, 보안, 수출 통제 문제와 함께 프롬프트 인젝션, 폭주 에이전트의 위험도 논의합니다.

3. **모델이 풀 수 있는 목표 정의와 숨은 비프음 찾기**
   - 모델이 해결할 수 있도록 목표를 명확히 정의하는 일이 중요하다고 강조합니다.
   - 코딩 에이전트로 40개 상자 속에 묻힌 비프음 감지기를 찾아낸 사례로 끈질긴 문제 해결 능력을 보여 줍니다.

4. **바이브 코딩 게임 개발**
   - 너구리 강도 이야기에서 시작해 실제로 플레이할 수 있는 게임을 만드는 과정을 소개합니다.
   - 바이브 코딩으로 만든 게임을 어떻게 재미있게 만들 것인지도 다룹니다.

5. **소프트웨어 엔지니어링은 왜 더 어렵게 느껴지는가**
   - AI로 생산성이 올랐는데도 소프트웨어 엔지니어링이 여전히, 혹은 더 어렵게 느껴지는 이유를 질문으로 던지며 마무리합니다.

## [New Ways of Working with Codex — Dominik Kundel & Charlie Guo, OpenAI](https://www.youtube.com/watch?v=IPh9YsWvDQk)

**한 줄 인사이트**
💡 Codex는 코드 작성 도구를 넘어 플러그인, 클라우드, 음성, 병렬 에이전트가 연결된 일상 업무 환경으로 확장되고 있습니다.

**핵심 요약**
OpenAI의 Dominik Kundel과 Charlie Guo가 CODE Summit 2026에서 Codex를 활용한 연결형 에이전트 워크플로를 시연합니다. 컨텍스트 수집에서 시작해 빠른 UI 반복, 클라우드 실행, 배포, 코드 리뷰까지 작업 흐름을 따라가며 각 기능이 어떻게 맞물리는지 보여줍니다. 영상 설명 기준으로 정리했으며, 세부 발언은 확인되지 않았습니다.

1. **컨텍스트 수집과 협업**
   - 플러그인, Appshots, 컴퓨터 사용 기능으로 Codex에 필요한 맥락과 공유 지식을 모아주고, 프라이버시 이슈도 함께 다룹니다.
   - ChatGPT Space를 통한 협업 방식도 소개됩니다.

2. **빠른 UI 반복 작업**
   - Ultrafast 모드와 주석(annotation) 기능으로 화면을 빠르게 수정하고 반복하는 흐름을 보여줍니다.
   - 사내 영상 앱 사례에서는 Codex가 DaVinci Resolve에서 영상을 편집해 검토용 컷을 돌려줍니다.

3. **클라우드 실행과 배포**
   - Codex Cloud와 원격 환경으로 작업을 로컬 밖에서 실행하는 방법을 설명합니다.
   - ChatGPT Sites와 Cutroom을 이용해 결과물을 실제로 배포하는 과정까지 이어집니다.

4. **코드 리뷰, 음성, 병렬 에이전트**
   - Codex 코드 리뷰, 음성 입력, Dots, Agents API가 일상 업무에 어떻게 녹아드는지 보여줍니다.
   - 모델과 추론 강도(reasoning effort) 선택, 병렬 에이전트 운용, CLI와 단축키 팁으로 마무리합니다.

## [4시간의 캐릭터, 선물, 게임: 일은 AI에게 맡기고 시청자와 함께 놀다](https://www.youtube.com/watch?v=leh29IZmZFc)

**한 줄 인사이트**
💡 AI가 일을 대신하면 사람이 할 일은 "함께 노는 것"이라는 답을 채팅 참여형 라이브로 직접 실험해 보였다.

**핵심 요약**
채널 운영자 윤자동이 11월 12일 라이브 방송을 편집한 영상으로, "AI가 모든 일을 하면 인간은 무엇을 하나"라는 질문에서 출발한다. 채팅 참여자를 각자 캐릭터로 만들어 화면을 채우고, 1대1 대결과 숫자 맞히기 게임, 선물 상자 웹사이트로 이어가며 그 답을 보여준다. 여기에 목소리를 복제한 AI 진행자 '짭자동'까지 등장해 시청자 질문에 답한다.

1. **일은 AI가, 사람은 함께 놀기**
   - 방송의 핵심 주제는 AI가 일을 맡는 시대에 사람이 할 일은 "같이 노는 것"이라는 결론이다.
   - 11월 12일 라이브에서 이 가설을 시청자와 직접 놀아 보며 확인했다.

2. **채팅 참여자가 캐릭터가 되는 마을**
   - 채팅에 참여한 시청자마다 캐릭터가 만들어져 화면을 채우는 '채팅 캐릭터 마을'이 구성된다.
   - 캐릭터 이미지는 GPT 이미지로, 게임 보드는 Claude Code로 제작했으며 닉네임은 실제 방송 화면 그대로 사용했다.

3. **선물 상자와 게임 콘텐츠**
   - 라이브 중 만들어진 결과물을 모아 선물 상자 웹사이트로 시청자에게 공유한다.
   - 1대1 대결과 숫자 맞히기 대회를 진행하며 시청자가 직접 참여하게 했다.

4. **AI 진행자 '짭자동'과 AI 제작물**
   - 윤자동의 목소리를 복제한 AI 진행자 짭자동이 화면에 출연해 시청자 질문에 답한다.
   - 영상 속 음악도 AI로 만들었고, 배경음악만 무료 라이선스 곡인 Mixkit을 썼다.
