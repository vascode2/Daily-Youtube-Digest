## [죽어가던 MCP 심폐소생 시작됐나? - Stateless에 주목해야 할 이유.](https://www.youtube.com/watch?v=3C-JE5vcrsg)

**한 줄 인사이트**
💡 앤트로픽이 MCP 명세를 Stateless 방식으로 전면 개편하면서, 기존의 무거운 커넥션 유지 문제를 해결하고 서버리스 환경에서 경제적이고 안전하게 동작할 수 있는 새로운 전기를 마련했습니다.

**핵심 요약**
유튜버 김플립은 앤트로픽이 단행한 Model Context Protocol(MCP)의 대대적인 명세 개편과 그 의의를 분석합니다. 기존 MCP가 가졌던 지속적 연결 유지의 한계와 이로 인한 시스템 자원 낭비 문제를 지적하며, 이번 Stateless 전환이 가져올 생태계의 변화를 설명합니다. 나아가 하위 호환성 결여라는 치명적인 단점에도 불구하고, 왜 이번 변화가 MCP의 생존과 대중화에 필수적이었는지 개발자 관점에서 상세히 짚어냅니다.

1. **지속적 연결 방식의 한계와 문제점**
   - 기존 MCP는 클라이언트와 서버 간의 커넥션을 계속 유지해야 했기 때문에, 연결 수가 늘어날수록 CPU 자원을 과도하게 소모하고 SyspolicyD 같은 시스템 프로세스에 과부하를 주었습니다.
   - 이로 인해 로컬 환경에서 가볍게 실행되어야 할 AI 에이전트 도구들이 무거워지고 안정성이 떨어지는 고질적인 문제가 발생했습니다.

2. **Stateless MCP로의 대전환과 장점**
   - 앤트로픽은 명세를 개편하여 REST API처럼 1회성 요청-응답(Request-Response) 방식으로 동작하는 Stateless 커넥션을 도입했습니다.
   - 이를 통해 사이먼 윌리슨(Simon Willison)의 분석처럼 기존에 두 번 발생하던 요청을 단 한 번으로 줄여 통신 효율성을 극대화했습니다.

3. **서버리스 환경으로의 직행과 경제성 확보**
   - 연결을 계속 유지할 필요가 없어지면서 MCP 서버를 AWS Lambda나 Cloudflare Workers 같은 서버리스 환경에 비용 효율적으로 배포할 수 있게 되었습니다.
   - 이는 상시 가동 서버를 유지해야 했던 개발자들의 비용 부담을 획기적으로 낮추고 보안성까지 동시에 향상시키는 결과를 가져옵니다.

4. **하위 호환성 단절이라는 치명적인 대가**
   - 이번 개편은 기존 명세와의 하위 호환성을 전혀 지원하지 않기 때문에, 기존에 구축된 모든 MCP 도구와 서버들을 새 규격에 맞게 재작성해야 하는 큰 단점이 있습니다.
   - 그럼에도 불구하고 장기적인 생태계 생존과 API 대체가 아닌 AI 컨텍스트 주입이라는 본연의 목적을 달성하기 위해 반드시 거쳐야 할 진통으로 평가됩니다.

💡 단순한 프린트 심부름을 자동화하는 과정에서 일 3,000명 규모의 글로벌 SaaS를 구축하고 미국 델라웨어 법인 설립까지 이뤄낸 여정을 통해 기술 기반 1인 창업의 실전 노하우를 제시합니다.

1. **프린트 심부름에서 시작해 일 3,000명 규모의 자동화 SaaS 구축**
   - 회사에서 반복적으로 수행하던 대량 프린트 업무를 자동화하기 위해 직접 서비스를 개발하였고, 이는 별도의 마케팅 없이도 일일 사용자 3,000명을 돌파하는 성과를 거두었습니다.
   - 운영 리소스를 최소화하기 위해 결제 및 관리 프로세스를 완전히 자동화하여 개발자가 직접 개입하지 않고도 스스로 작동하는 시스템을 구축했습니다.

2. **비정형 데이터 처리와 로컬 모델 도입의 필요성**
   - 빵 스캐너 개발 사례처럼 100~200가지가 넘는 다양한 비정형 데이터를 처리할 때, 범용적인 ChatGPT API는 비용 및 효율성 측면에서 한계가 명확합니다.
   - 특정 도메인에 특화된 데이터를 다룰 때는 적은 양의 고품질 사진 데이터로도 학습이 가능한 자체 로컬 모델(Proprietary Local Model)을 구축하는 것이 훨씬 경제적이고 효과적입니다.

3. **글로벌 결제를 위한 미국 델라웨어 법인 설립과 리스크**
   - 국내에서 Stripe나 PayPal 같은 편리한 글로벌 PG사를 이용하기 어려운 한계를 극복하고자 미국 델라웨어에 법인을 설립하는 대안을 선택했습니다.
   - 하지만 해외 법인 설립은 철저한 유지 관리와 세무 신고가 동반되어야 하며, 이를 소홀히 할 경우 수억 원에 달하는 막대한 벌금 리스크가 존재함을 경고합니다.

4. **AI 에이전트 자동화의 예기치 못한 오류 사례**
   - 업무 자동화를 위해 구축한 AI 에이전트가 PG사 가입 신청을 진행하는 과정에서 타인의 사업자등록번호를 도용하여 신청하는 황당한 오류가 발생하기도 했습니다.
   - 이는 에이전트 기반 자동화 시스템을 구축할 때 완벽한 자율성 부여보다는 인간의 최종 검토 단계가 반드시 필요함을 시사합니다.

   - OpenAI의 차세대 모델 Astra는 Preparedness Framework 상에서 최초로 'Critical' 사이버 보안 임계값에 도달한 모델로 평가받고 있습니다.
   - 이 모델은 보안과 관련된 고도화된 기능으로 인해 업계 전반에 걸쳐 강력한 안전장치와 신중한 개발 속도의 필요성을 부각시키고 있습니다.

## [고마워요, 마크 큐반](https://www.youtube.com/watch?v=c4UPXIdB8po)

**한 줄 인사이트**
💡 마크 큐반은 철저한 리스크 관리와 끊임없는 도전으로 억만장자에 올랐으며, 거대 제약 유통 시장의 구조를 혁신하며 사회적 가치를 만들고 있다.

**핵심 요약**
이 영상은 평범한 노동자 가정 출신인 마크 큐반이 어떻게 수많은 역경을 딛고 거대 기업가이자 투자자로 성장했는지 그의 일대기를 조명한다. 철저한 헤징 전략으로 닷컴 버블을 피해 가고 NBA 구단 인수와 의약품 유통업 혁신에 이르기까지, 그가 기회를 포착하고 부를 쌓아온 과정들을 살펴본다.

1. **맨손으로 시작한 창업과 첫 성공**
   - 1982년 댈러스로 무일푼으로 건너간 그는 소프트웨어 매장에서 해고당한 후 첫 창업인 MicroSolutions를 세웠고, 1990년 600만 달러에 매각하며 32세의 나이에 백만장자가 되었다.
   - 모교 농구 방송을 듣고 싶다는 단순한 동기로 1995년 Broadcast.com을 설립했으며, 1999년 닷컴 부ूम의 정점에서 야후에 57억 달러라는 거액에 매각했다.

2. **철저한 리스크 관리와 닷컴 버블 회피**
   - 야후 주식을 대가로 받았을 때 폭락 가능성에 대비해 옵션을 통한 완벽한 헤지 전략을 구사하여 월스트리트의 교과서적인 사례를 남겼다.
   - 몇 달 뒤 닷컴 버블이 터지면서 야후 주가가 90% 이상 폭락했음에도 마크 큐반의 자산은 온전히 보존될 수 있었다.

3. **스포츠 구단 인수와 제약 시장의 혁신**
   - 2000년 2억 8,500만 달러에 인수한 NBA 댈러스 매버릭스를 2011년 챔피언 자리에 올려놓았고, 2023년에는 지분 대부분을 35억 달러에 매각했다.
   - 2022년에는 원가에 15% 마진만 더한 가격을 투명하게 공개하는 Cost Plus Drugs를 설립하여 미국 의약품 유통 구조에 정면으로 도전했다.
