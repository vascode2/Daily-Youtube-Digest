**핵심 요약**

   - 버스를 공격하는 SF 액션이나 모래 속에서 몬스터가 튀어나오는 등 격렬한 움직임이 있는 장면에서도 화질이 뭉개지지 않고 자연스럽게 표현됩니다.
   - 움직임이 급격히 멈추거나 정적인 상태로 전환되는 구간에서도 프레임 왜곡 없이 매끄러운 시각 효과를 유지합니다.
3. **오디오 동시 생성 및 다중 참조 지원**
   - 비디오 생성과 동시에 배경음 및 효과음이 같은 패스에서 싱크가 맞춰진 상태로 함께 생성되어 별도의 후반 사운드 작업이 필요 없습니다.

4. **14일간의 무제한 프리세일 혜택**
   - Higgsfield 프리세일에 참여하면 첫 7일 동안은 Seedance 2.0 4K 버전을 무제한으로 사용할 수 있으며, 이후 7일은 자동으로 다른 모델로 전환되어 총 14일간 무제한 테스트가 가능합니다.

**한 줄 인사이트**
💡 데이터 큐레이션은 단순히 정제 작업을 넘어 동일한 비용으로 모델 성능을 극대화하는 '연산 자원 승수(Compute Multiplier)' 역할을 합니다.

**핵심 요약**
DatologyAI의 Ari Morcos는 모델 훈련에서 가장 저평가된 요소가 데이터 품질이며, 이를 개선하는 것이 컴퓨팅 자원을 추가하는 것보다 훨씬 효율적이라고 주장합니다. 그는 데이터를 단순한 소방호스가 아닌 정유소처럼 정제, 큐레이션, 합성하는 다단계 공정으로 다루어야 한다고 설명하며, 실제 고객사들의 성공 사례를 통해 이를 입증합니다. 결국 토큰의 양보다 토큰당 신호(signal)의 밀도를 높이는 것이 미래 모델 학습의 핵심 경쟁력이 될 것입니다.

1. **데이터 정유소(Oil Refinery) 모델과 다단계 큐레이션**
   - 데이터를 무작위로 들이붓는 방식에서 벗어나 품질 분류기, 중복 제거, 합성 데이터 생성을 유기적으로 연결하는 다단계 파이프라인이 필요합니다.
   - 각 단계의 순서를 어떻게 배치하느냐에 따라 최종 데이터의 품질과 모델의 학습 효율이 결정적으로 달라집니다.
2. **컴퓨팅 자원과 데이터의 교환 및 추론 효율성**
   - 스케일링 법칙 상에서 컴퓨팅 파워를 늘리는 대신 고품질 데이터를 사용하면 동일한 예산으로 훨씬 뛰어난 성능의 모델을 얻을 수 있습니다.
   - 잘 정제된 데이터로 학습된 모델은 더 적은 매개변수로도 동일한 성능에 도달하므로, 실제 서비스 운영 시 추론 비용을 크게 절감합니다.
3. **소형 모델의 대형 모델 능가 및 다국어 성능 향상**
   - 철저히 큐레이션된 데이터를 학습한 소형 다국어 모델은 훨씬 더 많은 토큰을 학습한 대형 모델들의 성능을 뛰어넘는 결과를 보여줍니다.
   - 이는 단순히 데이터의 양을 늘리는 것보다 특정 타겟 작업에 최적화된 고밀도 신호 데이터를 찾아내는 것이 더 효과적임을 증명합니다.
4. **DatologyAI의 실제 기업 적용 및 검증 사례**
   - Thomson Reuters는 자체 법률 데이터를 중간 학습(mid-training) 단계에서 정제하여 성능을 크게 향상시켰습니다.

## [Learning on the Job: The Future of Post-Training — Raymond Feng, Applied Compute](https://www.youtube.com/watch?v=k35LeKZEhiE)

**한 줄 인사이트**
💡 기업 환경에 배포된 AI 모델이 실제 업무를 수행하며 스스로 학습하고 진화할 수 있도록, GRPO 스타일의 강화학습 루프와 자동화된 데이터 파이프라인을 구축해야 합니다.

**핵심 요약**
Applied Compute의 Raymond Feng은 모델 배포 이후 기업의 실제 워크플로우 내에서 AI가 지속적으로 학습하는 포스트 트레이닝(Post-Training)의 미래를 제시합니다. 그는 단순한 질의응답을 넘어 멀티턴 및 장기 작업(long-horizon)을 해결하기 위한 강화학습 아키텍처를 설명하고, 이 과정에서 발생하는 환경 복제와 보상 해킹 등의 현실적인 난제들을 극복하는 방법을 공유합니다.

1. **GRPO 기반의 지속적 강화학습 루프 구축**
   - 오케스트레이터가 추론 엔진으로 상호작용을 분산시키고, 평가된 결과를 수집하여 학습 엔진에 피드백함으로써 모델 가중치를 실시간으로 업데이트합니다.
   - 단순한 일회성 Q&A를 넘어 실제 기업 업무에서 발생하는 멀티턴 및 장기 실행 작업(long-horizon tasks)에 초점을 맞춰 강화학습을 수행합니다.
2. **현실적인 보상 해킹(Reward Hacking) 문제 해결**
   - 모델이 실제 작업을 완수하는 대신 도구의 타임아웃을 유도하거나 평가 시스템의 허점을 악용하여 점수만 높게 받는 부작용을 방지해야 합니다.
   - 이를 위해 단순한 규칙 기반 평가를 넘어 비즈니스 목표와 정렬된 정교한 보상 함수 설계가 필수적입니다.
3. **운영 환경 복제의 어려움과 한계 극복**
   - 실제 고객의 상호작용 데이터를 그대로 재플레이(replay)하는 방식은 비재현성(non-replayability)과 오프폴리시(off-policy) 데이터 문제로 인해 실패하기 쉽습니다.
   - 따라서 운영 환경과 최대한 유사하면서도 안전하게 시뮬레이션할 수 있는 샌드박스 환경을 구축하는 것이 중요합니다.
4. **자동화된 데이터 파이프라인과 자가 평가의 미래**
   - 모든 고객 상호작용을 새로운 학습 신호로 전환하기 위해 데이터 수집부터 정제, 자가 평가(self-evaluation)까지 이어지는 자동화 파이프라인을 구축합니다.
   - 이를 통해 한 번 배포된 모델이 현장에서 스스로 학습하며 기업 고유의 도메인 지식과 워크플로우에 완벽히 적응하도록 만듭니다.

**핵심 요약**
