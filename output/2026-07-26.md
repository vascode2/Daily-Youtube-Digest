**핵심 요약**
풀사이드의 마라 압딘과 로버트 맥하디는 고품질 코드 데이터의 한계를 극복하기 위해 합성 데이터를 대량으로 생성하고 학습시키는 과정의 실제적인 노하우를 공개합니다. 이들은 난이도 조절과 다단계 변형을 거치는 합성 데이터 생성 기법부터, 학습 과정에서의 엄격한 복제 검증과 하드웨어 결함 포착 방법까지 대규모 모델 구축의 이면을 상세히 설명합니다.

1. **합성 데이터 생성과 난이도 제어**
   - 템플릿과 보조 컨텍스트를 결합하고 다양한 표현 방식으로 생성하여 모델이 학습하기에 너무 쉽지도 어렵지도 않은 최적의 난이도를 유지합니다.
   - 단일 프롬프트를 멀티턴 대화로 전환하고, 오케스트레이터가 부적절한 생성을 실시간으로 필터링하여 데이터의 품질을 관리합니다.

2. **다단계 파이프라인과 데이터 변형**
   - 기존 데이터를 새로운 형태로 변환하고 캐릭터 스타일이나 플롯을 교체하여 다양한 학습 시나리오를 만들어냅니다.
   - 고갈되는 실제 코드 데이터를 보완하기 위해 모델이 스스로 학습할 수 있는 유효한 교육용 데이터를 다각도로 제조합니다.

3. **사전 학습 단계의 엄격한 무결성 검증**
   - 동일한 데이터로 두 개의 모델 복제본을 실행하여 결과값이 정확히 일치하지 않으면 즉시 학습을 중단하는 철저한 검증 원칙을 고수합니다.
   - 손실 곡선의 이상 형태로 드러나는 고장 난 GPU와 텐서 병렬 누적의 수치적 정밀도 버그를 찾아내어 대규모 학습의 실패를 방지합니다.

4. **118B 코딩 모델의 성과**
   - 엄격한 검증과 확장 가능한 레시피를 바탕으로 구축된 118억 파라미터 규모의 에이전틱 코딩 모델은 초기 테스트에서 GLM 4.5 Air를 능가하는 성능을 보여줍니다.
   - 대규모 스케일링 과정에서 발생하는 침묵의 구배 손상과 레이스 컨디션 같은 사각지대를 극복하며 실질적인 성과를 입증했습니다.
