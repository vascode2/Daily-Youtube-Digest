3. **미감도 실력이 된다**

## [All Code Is Slop (Except Mine) — Lauren Tan, SpaceXSI](https://www.youtube.com/watch?v=O_zcc6Xl12g)

**한 줄 인사이트**
💡 SpaceXSI의 Grok Bot 팀은 한 달에 PR 11,000건을 병합하고도 revert 비율을 약 0.5%로 유지했으며, 그 비결로 AI 에이전트의 능력보다 소프트웨어 엔지니어링 기본기와 검증 체계를 꼽는다.

**핵심 요약**
Cursor에서 일했던 Lauren Tan(poteto)이 SpaceXSI의 Grok Bot 팀 사례를 바탕으로, AI가 쓴 코드를 어떻게 믿을 수 있게 만드는지 설명한다. 코드베이스 품질과 아키텍처 규칙에서 출발해 lint, 런타임 검증, 형식 검증까지 신뢰 수준을 단계적으로 쌓아 올리고, 이를 토대로 소프트웨어 팩토리로 나아가야 한다고 주장한다.

1. **신뢰 피라미드와 코드베이스 품질**
   - 에이전트가 만든 코드를 신뢰하려면 코드베이스 자체의 품질이 먼저 받쳐줘야 한다는 "신뢰 피라미드" 관점을 제시한다.
   - 이 기본기가 없는 상태에서 에이전트를 확장하면 결과물이 곧 slop이 된다고 본다.

2. **강제 가능한 아키텍처와 lint 규칙**
   - Dune 사례를 통해 사람이 읽는 문서가 아니라 기계가 강제할 수 있는 아키텍처를 만드는 방법을 설명한다.
   - 코드 주석으로 남기던 규칙을 lint 규칙으로 대체해, 에이전트가 위반하면 즉시 걸러지도록 한다.

3. **런타임 검증과 형식 검증**
   - 기능 맵(feature map)을 활용한 런타임 검증으로 실제 동작을 확인한다.
   - TLA+와 Lean을 이용한 형식 검증과 UI 테스트를 병행해 검증 범위를 넓힌다.

4. **검증에 토큰을 쓰는 전략과 성과**
   - 코드를 생성하는 데만 쓰지 않고 검증에도 토큰을 적극적으로 투입하는 것이 핵심이라고 말한다.
   - 그 결과 한 달간 PR 11,000건, revert 비율 약 0.5%를 달성했으며, Cursor 에이전트와 pstack으로 이를 구현한다.
