Hariprasad Sudharshan은 2년간의 1인 개발 끝에 수많은 개발자가 서로 모방하지 않고도 동일한 도구와 모델 덕분에 똑같은 결과물에 도달한다는 사실을 발견한다. 그는 이러한 공통의 출발점을 '미디언(Median)'이라 부르며, 작동하는 데모만으로는 지속 가능한 제품 우위를 점할 수 없다고 경고한다. 이어 AI 시대에 엔지니어가 빠지기 쉬운 개발 함정을 짚어보고, 실질적인 차별화를 만들기 위한 구체적인 전략을 제시한다.

   - 동일한 AI 모델과 개발 도구를 사용하면 개발자들은 서로를 모방하지 않아도 자연스럽게 똑같은 결론과 솔루션에 도달하게 된다.
   - 이러한 공통의 출발점을 저자는 '미디언(Median)'이라 정의하며, 빠른 개발 속도로 유용한 소프트웨어를 쉽게 만들 수 있지만 그 자체만으로 제품의 지속적인 우위가 되지는 않는다.

3. **데모 평가를 위한 세 가지 핵심 질문**
   - 리더들이 새로운 AI 데모를 평가할 때는 이미 누가 이 문제를 해결했는지 객관적으로 파악해야 한다.

4. **오픈 웨이트와 인프라 비용의 재조명**
   - 기업 내부에서 오픈 모델 웨이트를 직접 구동하는 것과 단순히 추론 능력을 구매하는 것은 인프라와 활용도 측면에서 큰 차이가 난다.

## [Paving the Road to Production: Governed Enterprise AI Agents — Harish Gaggar, Credit Karma](https://www.youtube.com/watch?v=tZycGA_Fbfo)

**한 줄 인사이트**
💡 엔터프라이즈 환경에서 AI 에이전트를 성공적으로 운영하려면 개별 에이전트 개발을 넘어 인증 게이트웨이, 메모리, 모니터링, PII 차단, 컨텍스트 최적화 등 종합적인 인프라 프레임워크를 처음부터 구축해야 합니다.

**핵심 요약**
Intuit Credit Karma의 하리쉬 가가(Harish Gaggar)가 실험 단계에 머무는 AI 에이전트를 실제 프로덕션 환경으로 안전하게 전환하는 방법과 필수 인프라 아키텍처를 상세히 소개합니다. 개발 포털을 통한 표준화된 리포지토리 및 리소스 프로비저닝부터 중앙 집중식 MCP 게이트웨이를 통한 보안 인증, 그리고 LangGraph 기반 워크플로우와 컨텍스트 최적화까지 엔터프라이즈 에이전트 구축의 전 과정을 다룹니다.

1. **에이전트 인프라 구축과 로컬 개발 프로세스**
   - 개발 포털을 통해 에이전트 유저케이스와 프레임워크를 등록하면 LangGraph 에이전트 코드뿐만 아니라 메모리, 트래킹, PII 차단, 컨텍스트 최적화 프레임워크가 포함된 표준화된 리포지토리와 프로덕션 리소스가 함께 생성됩니다.
   - 개발자는 로컬에서 Docker 컨테이너와 SQLite 등을 활용해 입출력을 테스트하고 PR 승인을 거쳐 CI/CD 파이프라인을 통해 Kubernetes 클러스터에 안전하게 배포할 수 있습니다.

2. **MCP 게이트웨이와 커스텀 MCP 서버를 통한 보안 라우팅**
   - 에이전트와 도구 간의 직접 통신을 차단하고, 모든 요청은 인증을 처리하는 중앙 집중식 MCP 게이트웨이를 거치도록 하여 Redis에 세션 상태를 저장하고 JWT 토큰 기반으로 안전하게 라우팅합니다.
   - 에어갭 환경에서는 Fast MCP 패키지로 자체 MCP 서버를 구축하고, 내부 보안팀의 검증을 거친 승인된 툴만 사용하여 민감 정보 노출을 방지합니다.

3. **LangGraph 워크플로우와 상태 관리**
   - LangGraph를 활용해 질문을 분석 및 분류하고, 읽기 작업과 민감한 쓰기 작업을 구분하여 민감 작업 시 HITL(Human-in-the-Loop) 승인 프로세스를 거치도록 설계했습니다.
   - 스레드와 런 ID 기반으로 각 노드의 체크포인트를 생성하며, 로컬 SQLite와 프로덕션 Cloud Spanner 등을 통해 워크플로우 상태를 안정적으로 복구합니다.

4. **추적, 평가 및 PII 보안 처리**
   - 100개 이상의 에이전트 프로젝트에서 질의응답, 토큰 사용량, 비용, 툴 호출 성공 여부 등을 개별 테이블에 기록하여 통합 대시보드와 ROI 측정이 가능하도록 지원합니다.
   - 90% 이상의 심각도를 가진 PII 및 API 키 같은 민감 데이터는 입력 시점에 즉시 차단 및 마스킹 처리하여 LLM 모델이나 메모리 DB, 트레이싱 시스템에 유입되지 않도록 보호합니다.

5. **컨텍스트 최적화를 통한 토큰 비용 절감**
   - 대규모 컨텍스트를 LLM에 전달하기 전 토큰 제한에 맞춰 payload를 선별하고, 연관성 높은 정보를 재랭킹(re-rank)하며 중복을 제거 및 압축하는 최적화 프레임워크를 적용합니다.
   - 실제 데모 시연 결과, 컨텍스트 최적화를 켜면 동일한 쿼리에서 24,000개의 토큰이 2,400개 이하로 줄어들어 약 90%의 토큰 비용 절감 효과를 보여줍니다.
