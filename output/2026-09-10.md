## [Generative UI... in Python? — Jeremiah Lowin, Prefect](https://www.youtube.com/watch?v=Krzs8GeiWTc)

**한 줄 인사이트**
💡 Python 기반 기업용 엔지니어들이 리액트 없이도 인터페이스를 구축할 수 있도록 돕는 Python DSL 기반의 Generative UI 프레임워크인 Prefab을 소개한다.

**핵심 요약**
Prefab의 창시자이자 Prefect CEO인 Jeremiah Lowin은 MCP 앱이 에이전트 통신 문제를 해결하면서도 파이썬 엔지니어들에게 프론트엔드 개발이라는 새로운 과제를 안겨주었다고 설명한다. 그는 문제의 범위를 테이블, 폼, 차트 등으로 제한하고 컨텍스트 매니저를 중첩하는 Python DSL 방식을 도입함으로써 에이전트가 직접 생성하고 수정할 수 있는 직렬화된 UI 파이프라인을 완성했다.

1. **MCP 앱과 에이전트 우회 문제**
   - MCP 서버에 접근하는 에이전트 때문에 발생하는 비효율적인 파일 업로드 과정을 세계에서 가장 비싼 복사-붙여넣기 작업으로 정의하며, MCP 앱은 이를 해결하기 위해 등장했다.
   - 툴의 결과가 에이전트를 건너뛰고 사용자에게 HTML, CSS, JavaScript 형태의 실제 클릭 가능한 인터페이스로 전달되는 방식을 지원한다.

2. **파이썬 엔지니어를 위한 제약과 문제 해결**
   - 대다수의 사용자가 엔터프라이즈 환경의 파이썬 엔지니어라는 점에 착안하여, 파이썬만으로 리액트 기반 프론트엔드를 다루는 한계를 극복하고자 했다.
   - 소비재 브랜딩 제품이 아닌 정보 공유와 수집에 초점을 맞춰 테이블, 폼, 차트 중심으로 문제를 의도적으로 제한했다.
